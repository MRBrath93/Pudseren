# Pudseren

Webapplikation til et lille vinduespudsningsfirma, der erstatter papirkort.
Chefen holder styr på kunder og ruter ved computeren, og medarbejderen arbejder fra telefonen.

Bachelorprojekt, Professionsbachelor i webudvikling, IBA Kolding.

## Teknologi

- Klient: Vue 3 og Vite
- Server: Node.js og Express
- Database: PostgreSQL
